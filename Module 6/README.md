
# Module 6 - Introduction to Python Modules

CSS 225 - Python Programming

This module focuses on using Python's random and math modules.

Programs included:
1. randomrange.py - Generates 10 random integers.
2. randomint.py - Generates a random odd integer.
3. randomday.py - Selects a random day of the week.
4. pi.py - Calculates an approximation of pi.
5. degrees.py - Converts radians to degrees.
6. factorial.py - Calculates the factorial of a number.

All programs were created as part of my Module 6 lab activity.
