## Description

This lab focuses on using Boolean expressions, conditional statements, functions, and logical operators in Python. The purpose of this assignment is to practice comparing values, checking conditions, and using True and False results to make decisions in a program.

## Programs Included

### Problem 1 – Equal or Not Equal
- File: `problem1_equal.py`
- Takes two inputs from the user.
- Checks whether the values are equal or not equal.

### Problem 2 – Sum Comparison
- File: `problem2_sum.py`
- Takes two numbers from the user.
- Determines whether their sum is greater than, less than, or equal to 10.

### Problem 3 – Check a List
- File: `problem3_list.py`
- Checks whether the number 5 exists in a list.
- Prints a message based on the result.

### Problem 4 – Leap Year
- File: `problem4_leap_year.py`
- Uses Boolean conditions to determine whether a year is a leap year.
- Follows the rules for years divisible by 4, 100, and 400.

### Problem 5 – Dragon Slayer Character
- File: `problem5_character_tasks.py`
- Uses the character class provided by the instructor.
- Checks whether the Dragon Slayer has the required items and does not have weaknesses that prevent completing a task.
- Tests three tasks:
  1. Climb a mountain
  2. Cook a meal
  3. Write a book

## How to Run the Programs

1. Download the Python files.
2. Open Python IDLE.
3. Click File → Open.
4. Select the Python file you want to run.
5. Press F5 to execute the program.
6. Follow the prompts or review the displayed results.
