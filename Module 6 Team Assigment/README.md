## Number Guessing Game

This program uses Python's random module to generate
a number between 1 and 100.

The user enters a guess, and the program tells them
whether their guess is too high, too low, or correct.

## Features
- Random number generation
- Nested if...else statements
- User input
- Higher and lower hints
- Input validation
- Extra credit: Play again using Y or N

## How to Run
1. Open the Python file in IDLE.
2. Press F5.
3. Enter a number between 1 and 100.
4. Follow the hints until you guess correctly.
5. Choose Y to play again or N to exit.
